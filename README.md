# UI Knowledge Base

## Назначение

UI Knowledge Base — постоянная база интерфейсов программ, которыми Анна пользуется регулярно.

Цель базы:

- сохранять реальные карты интерфейсов;
- фиксировать реальные названия кнопок и меню;
- сохранять маршруты навигации;
- фиксировать типичные ошибки и способы решения;
- уменьшать количество повторных объяснений;
- использовать базу как единый источник истины для ChatGPT, Claude и Codex.

## Правило работы

Перед выдачей технических инструкций необходимо:

1. Проверить наличие карты интерфейса в папке interfaces.
2. Использовать реальные названия кнопок и разделов.
3. Не придумывать навигацию по памяти.
4. При расхождении интерфейса запрашивать новый скриншот.
5. После подтверждения обновлять описание интерфейса.

---

## Что должно храниться в каждой карте интерфейса

- название программы;
- версия интерфейса;
- дата актуализации;
- карта экранов;
- карта навигации;
- частые сценарии;
- типичные ошибки;
- эталонные скриншоты;
- особенности конкретного аккаунта Анны.

## Правило для VPN-инфраструктуры

При диагностике проблем соблюдать порядок:

Маршрут
↓
DNS
↓
Авторизация / браузер
↓
VPS

Не считать любую проблему Claude, ChatGPT или Gemini автоматически проблемой VPS.
