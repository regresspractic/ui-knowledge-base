# UI Knowledge Base — Project Rules

Дата актуализации: 2026-06-02

## Цель

UI Knowledge Base — постоянная текстовая база интерфейсов программ, которыми Анна пользуется регулярно.

Главная цель: ChatGPT, Claude и Codex должны работать по документированным интерфейсам, а не по памяти старых скриншотов.

## Главный источник истины

GitHub-репозиторий regresspractic/ui-knowledge-base является основным источником истины по интерфейсам.## Работа со скриншотами

1. Смотреть все присланные скриншоты.
2. Не пропускать ни один экран.
3. Не додумывать названия кнопок, вкладок и пунктов меню.
4. Фиксировать только реально видимые элементы интерфейса.
5. Если элемент плохо читается — просить новый скриншот.
6. Если есть сомнение — явно отмечать это в карте интерфейса. ## Структура карты интерфейса

Каждый файл в папке interfaces должен содержать:

- название интерфейса;
- версия интерфейса;
- дата актуализации;
- карта экранов;
- карта навигации;
- частые сценарии;
- типичные ошибки;
- особенности аккаунта пользователя;
- эталонные скриншоты;
- статус актуальности.

## Правило обновления карт

При появлении новых скриншотов:

Сравнить с текущей картой
↓
Выявить изменения
↓
Обновить описание
↓
Записать изменение в CHANGELOG.md ## Диагностика VPN и AI-доступа

Порядок диагностики:

1. Маршрут VPN.
2. DNS / connectivity.
3. Авторизация / браузер / cookies / app session.
4. VPS / серверная инфраструктура.

Нельзя автоматически считать любую проблему Claude, ChatGPT, Gemini, YouTube или Netflix проблемой VPS.

## Что не трогать до завершения базы

До завершения первичной UI Knowledge Base не менять и не чистить:

- Turkish VPS;
- Happ;
- Hiddify;
- FRDM;
- подписки;
- серверные ссылки;
- vpn.regresspractic.ru. ## Технические инструкции

Инструкции должны быть максимально конкретными.

Нужно указывать:

- точный путь файла;
- точную команду;
- точный текст для поиска;
- точный блок для вставки;
- одно действие за один шаг.

Не использовать TextEdit для создания .md файлов.

## Особенности пользователя

При составлении инструкций учитывать:

- пользователь работает на Mac;
- пользователь использует Codex, а не Cursor;
- пользователь предпочитает пошаговые инструкции;
- пользователь предпочитает терминал для работы с .md файлами;
- пользователь хочет предупреждение, когда чат становится слишком большим.
