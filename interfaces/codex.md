# Codex Desktop Interface Map

Дата актуализации: 02.06.2026  
Источник: скриншоты Codex Desktop, macOS.

## Назначение

Codex Desktop используется как рабочий интерфейс для AI-кодинга, проектов, чатов, доступа к файлам workspace, браузеру и терминалу.

Важно не путать три слоя:

1. Проект/чат в Codex.
2. Файловое дерево workspace внутри Codex.
3. Реальные папки на Mac.

## Главный экран

В центре экрана отображается вопрос:

> Над чем поработаем в Gleb?

Ниже находится поле ввода:

> Спросите что угодно

Под полем виден выбранный проект:

> Gleb

Справа в строке ввода отображается выбранная модель:

> 5.5 Средний

Также видны элементы:

- кнопка `+`;
- меню `Разрешения по умолча...`;
- микрофон;
- кнопка отправки сообщения.

## Левая боковая панель

В верхней части:

- Новый чат;
- Поиск;
- Плагины;
- Автоматизации.

Далее раздел:

> Проекты

Видимые проекты:

- codex-lab;
- Gleb.

Внутри проекта `Gleb` видны последние чаты:

- List files in skillopt;
- Add archive saving to ...;
- Create project structu...;
- Add main.py and requ...

Внизу левой панели:

- Настройки.

## Кнопка скрытия левой панели

В левом верхнем углу окна есть кнопка переключения боковой панели.

Подсказка на скриншоте:

> Скрыть боковую панель

или

> Переключить

Эта кнопка сворачивает/разворачивает левую навигационную панель.

## Правая боковая панель

Правая боковая панель открывается кнопкой в правом верхнем углу.

Подсказка:

> Показать/скрыть боковую панель

В открытой правой панели видны карточки:

### Файлы

Текст:

> Просмотреть файлы проекта

Горячая клавиша:

> ⌘P

Используется для просмотра файлов проекта/workspace.

### Браузер

Текст:

> Открыть сайт

Горячая клавиша:

> ⌘T

Используется для открытия сайта внутри Codex.

### Терминал

Текст:

> Запустить интерактивную оболочку

Используется для запуска терминала внутри Codex.

## Меню выбора внешнего приложения / IDE

В верхней правой части окна есть выпадающее меню с иконкой VS Code.

В меню доступны варианты:

- VS Code;
- Cursor;
- Finder;
- Terminal.

Это меню относится к открытию/переходу во внешние инструменты, а не к списку проектов Codex.

## Типичные ошибки

### Ошибка 1. Путать проект Codex и папку на Mac

Проект `Gleb` в левой панели Codex — это не обязательно то же самое, что папка на рабочем столе.

Перед инструкциями нужно уточнять или проверять реальный путь проекта на Mac.

### Ошибка 2. Путать список чатов и файловое дерево

Слева под проектом видны чаты, а не файлы workspace.

Для файлов нужно использовать правую панель:

> Файлы

или проверять файлы через терминал.

### Ошибка 3. Называть Codex Cursor

В текущем интерфейсе пользователь работает именно в Codex Desktop.

Cursor может быть только вариантом во внешнем меню, но не текущим рабочим интерфейсом.

### Ошибка 4. Давать абстрактные инструкции

Нельзя писать только:

> Открой файл

Нужно указывать:

- точный путь файла;
- точную команду для терминала;
- что именно скопировать;
- куда именно вставить;
- что проверить после изменения.

## Рабочее правило для инструкций

Для проектов в Codex сначала определить:

1. текущий проект Codex;
2. реальную папку проекта на Mac;
3. есть ли доступ к workspace files;
4. нужен ли терминал;
5. какой файл реально редактируется.

Только после этого давать команды.
