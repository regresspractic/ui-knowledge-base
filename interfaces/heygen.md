## Назначение

HeyGen используется для:

- создания AI-аватаров;
- создания Photo Avatars;
- создания Digital Twins;
- генерации видео;
- создания видео для сторис;
- создания видео для презентаций;
- работы с голосами;
- смены студий и фонов.

## Карта экранов

### Главный экран

Основные разделы:

- Avatars
- Videos
- AI Studio
- Voices
- Brand
- Assets

### Avatars

Содержит:

- My Avatars
- Public Avatars

Используется для управления личными аватарами и выбора публичных аватаров HeyGen.

### My Avatars

Отображаются собственные аватары пользователя.

Для каждого аватара доступны:

- просмотр;
- использование в видео;
- Edit Look;
- настройки аватара.

### Public Avatars

Каталог аватаров HeyGen.

Используется для быстрого создания видео без собственных аватаров.

### Edit Look

Важный экран.

Маршрут:

Avatar → My Avatars → выбрать аватар → Edit Look

Здесь изменяются:

- внешний вид аватара;
- причёска;
- одежда;
- внешний образ (Look).

Edit Look изменяет внешний вид самого аватара.

Не путать со Studio. ### Studio

Очень важный экран.

Назначение:

Studio определяет окружение, в котором находится аватар.

Studio изменяет:

- фон;
- интерьер;
- освещение;
- виртуальную студию.

Studio НЕ изменяет внешний вид аватара.

Маршрут:

Avatar → My Avatars → выбрать аватар → Edit Look → Studio

Особенность аккаунта пользователя:

В интерфейсе переход в Studio находится через левый нижний угол экрана Edit Look.

Это подтверждено скриншотами пользователя.

### Voice

Отдельный раздел интерфейса.

Назначение:

- создание голосов;
- управление голосами;
- привязка голоса к аватару;
- работа с Digital Twin.

Важно:

Voice является отдельным разделом интерфейса и не относится к настройкам Studio.

### AI Studio

Раздел для создания видео.

Используется для:

- создания роликов;
- выбора аватара;
- выбора голоса;
- генерации итогового видео.

### Quick Create

Быстрый сценарий создания видео.

Используется для быстрого запуска генерации без полного прохождения AI Studio. ## Частые сценарии

### Создание видео для сторис

Маршрут:

1. Открыть AI Studio.
2. Выбрать аватар.
3. Выбрать голос.
4. Вставить текст.
5. Сгенерировать видео.

### Изменение внешнего вида аватара

Маршрут:

1. Avatars.
2. My Avatars.
3. Выбрать аватар.
4. Edit Look.

### Изменение студии

Маршрут:

1. Avatars.
2. My Avatars.
3. Выбрать аватар.
4. Edit Look.
5. Studio.

Важно:

Студия меняет окружение, а не внешний вид аватара.

### Работа с голосом

Маршрут:

1. Voices.
2. Выбрать существующий голос или создать новый.
3. Использовать голос при генерации видео.

## Частые ошибки

### Ошибка 1

Путаница между Edit Look и Studio.

Правильно:

- Edit Look = внешний вид аватара.
- Studio = фон и окружение.

### Ошибка 2

Потеря экрана Studio.

Решение:

Перейти в Edit Look и использовать переход через левый нижний угол интерфейса.

### Ошибка 3

Путаница между My Avatars и Public Avatars.

Правильно:

- My Avatars = собственные аватары пользователя.
- Public Avatars = библиотека HeyGen.
