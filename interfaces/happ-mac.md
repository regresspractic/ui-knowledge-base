# Happ Mac — карта интерфейса

Дата актуализации: 2026-06-02

Статус: актуально по присланным скриншотам от 02.06.2026.

Платформа: macOS.

Язык интерфейса: русский.

Точная версия Happ на скриншотах не видна.

## Назначение карты

Эта карта нужна, чтобы в будущих технических инструкциях не путать:

- главный экран Happ Mac;
- экран настроек Happ Mac;
- меню добавления подписки / конфигурации;
- список подписок и отдельных серверных конфигураций;
- реальные папки macOS и файловое дерево проектов.

## Источники

Карта составлена по скриншотам Happ Mac от 02.06.2026:

- главный экран Happ с подключённым VPN;
- список маршрутов FRDM VPN;
- список маршрутов собственного VPS `38.180.113.171` / `38-180-113-171.sslip.io` / `vpn.regresspractic.ru`;
- экран `Настройки`;
- меню кнопки `+`;
- всплывающие ошибки сертификата и таймаута соединения.

Если новый скриншот противоречит этой карте, сначала сверить экран, затем обновить карту.

## Главное окно Happ Mac

Верхняя строка macOS, когда активно приложение Happ:

```text
Happ | Файл | Правка | Формат | Вид | Окно | Справка
```

Внутри окна Happ:

- вверху по центру — заголовок `Happ`;
- слева сверху — стандартные кнопки macOS: закрыть, свернуть, развернуть;
- под ними слева — иконка шестерёнки;
- справа сверху — кнопка `+`;
- в центре — большая круглая кнопка питания;
- под кнопкой питания отображается состояние подключения, например `ПОДКЛЮЧЕН`;
- под состоянием отображается длительность текущего подключения, например `3:48:58`;
- над списком маршрутов слева есть текст `Проверить текущее соединение`;
- над списком маршрутов справа есть действие `Скрыть все`.

## Центральная кнопка подключения

Центральная круглая кнопка показывает состояние VPN.

На скриншотах видимое состояние:

```text
ПОДКЛЮЧЕН
```

Под ним идёт таймер текущей VPN-сессии.

Важно: наличие статуса `ПОДКЛЮЧЕН` не означает, что конкретный сайт точно работает. Для диагностики нужно отдельно проверять слой проблемы:

1. профиль / транспорт VPN;
2. DNS / сетевую связность;
3. браузер / сессию / авторизацию сайта.

## Список маршрутов и подписок

Нижняя часть главного окна — список конфигураций.

Возможны два типа отображения:

1. отдельные маршруты без видимого заголовка подписки;
2. раскрытые группы подписок.

### Отдельная строка маршрута

Строка маршрута обычно содержит:

- слева флаг страны или серую иконку глобуса;
- рядом цветной индикатор состояния / качества;
- название маршрута;
- строку технических параметров под названием;
- справа задержку, например `273 мс`, `832 мс`, `6247 мс`, либо `n/a`;
- справа стрелку `>` для входа в детали маршрута.

Примеры названий маршрутов, видимых на скриншотах:

```text
FRDM - Обход TW
FRDM - Обход VK
FRDM - Обход YA
FRDM - Обход 15 ×2
FRDM - Обход 16
FRDM SMART ОБХОД
FRDM
FRDM - SMART
```

Примеры технических строк под маршрутом:

```text
VLESS | xhttp | TLS | JSON
VLESS | TCP | Reality | JSON
VLESS | WebSocket | TLS | JSON
VLESS | mKCP | None | JSON
Hysteria | hysteria | TLS
```

### Группа подписки

Группа подписки отображается отдельным блоком с заголовком.

Примеры заголовков на скриншотах:

```text
FRDM VPN
38-180-113-171.sslip.io
```

В заголовке группы видны:

- стрелка раскрытия / сворачивания слева;
- название подписки;
- строка даты обновления и автообновления, например `02.06.2026 09:58 | Автообновление - 1 ч.`;
- справа иконки управления группой: обновление, проверка / спидометр, меню `...`;
- полоса трафика;
- срок действия, например `Истекает: 19.08.2026` или `Истекает: 24.05.2036`.

На скриншотах видны примеры трафика:

```text
234 GB/1900 GB
706 MB/3000 GB
```

Внутри группы отображаются отдельные маршруты этой подписки.

## Кнопка `+` справа сверху

Кнопка `+` открывает меню добавления подписки или конфигурации.

Положение:

```text
главное окно Happ → правый верхний угол внутри окна → +
```

Меню содержит пункты:

```text
URL подписки
Вставить из буфера обмена
QR-код
Ручной ввод
Копировать JSON
```

Практическое различие:

- `URL подписки` — ручное добавление ссылки подписки;
- `Вставить из буфера обмена` — если ссылка уже скопирована;
- `QR-код` — добавление через QR;
- `Ручной ввод` — ввод конфигурации вручную;
- `Копировать JSON` — экспорт / копирование JSON, точное поведение нужно проверять на следующем скриншоте или действии.

## Типовые действия

### Добавить подписку по ссылке

Маршрут:

```text
главное окно Happ → + → URL подписки
```

или, если ссылка уже скопирована:

```text
главное окно Happ → + → Вставить из буфера обмена
```

Важно: для Hiddify/Happ нужно копировать именно subscription link / ссылку подписки, а не просто клиентскую страницу. Если вставить не ту ссылку, клиент может показать ошибку, что подписка не содержит действующей конфигурации.

### Открыть настройки

Маршрут:

```text
главное окно Happ → шестерёнка слева сверху
```

Назад:

```text
Настройки → стрелка < слева сверху
```

### Найти раздел подписок внутри настроек

Маршрут:

```text
главное окно Happ → шестерёнка → РАСШИРЕННЫЕ НАСТРОЙКИ → Подписки
```

Это не то же самое, что кнопка `+` на главном экране. `+` добавляет подписку / конфигурацию, а пункт `Подписки` в настройках ведёт к управлению подписками.

### Проверить текущий маршрут

На главном экране смотреть активную / выделенную строку маршрута и её техническую строку под названием.

Для AI-сервисов предпочтительно проверять, чтобы маршрут был из стабильных TCP / Reality / Vision-профилей, а не проблемный SMART / fragment-профиль.

## Частые ошибки, видимые на скриншотах

### Ошибка сертификата

Текст ошибки:

```text
Сертификат для данного сервера недействителен. Возможно, Вы подключаетесь к серверу, имитирующему «vpn.regresspractic.ru», что может подвергнуть риску Вашу конфиденциальную информацию.
```

Контекст на скриншоте: ошибка появляется при работе со строками `vpn.regresspractic.ru`.

Не делать автоматически:

- не менять серверную конфигурацию без диагностики;
- не удалять домен;
- не удалять подписку;
- не считать, что весь VPS сломан.

Сначала проверить слой проблемы: сертификат / домен / конкретный транспорт / профиль.

### Таймаут соединения

Текст ошибки:

```text
Время ожидания соединения истекло. Сервер не отвечает, или возможно проблема с интернет-соединением.
```

Не делать автоматически:

- не менять сразу Hiddify на сервере;
- не перегенерировать подписки;
- не удалять рабочие маршруты.

Сначала проверить другой стабильный маршрут и базовый интернет.

## Типичные пользовательские ловушки

1. Путаница между `+` и `Подписки` в настройках.

`+` — добавление новой подписки / конфигурации.

`Настройки → Подписки` — управление уже существующими подписками.

2. Путаница между группой подписки и отдельным маршрутом.

`FRDM VPN` или `38-180-113-171.sslip.io` — это блок подписки.

`FRDM - Обход 7 ×2` или `38.180.113.171 tls xhttp direct vless dl=h1` — это конкретный маршрут внутри списка.

3. Похожесть названий собственного VPS.

В интерфейсе одновременно могут быть строки с:

```text
38.180.113.171
38-180-113-171.sslip.io
vpn.regresspractic.ru
```

Перед инструкцией нужно точно назвать, какой вариант нужен.

4. SMART / fragmentation-профили.

По прошлой диагностике проекта SMART / fragment-профили могли вызывать ошибки XrayCore на Mac. В качестве стабильного fallback предпочтительны TCP Reality / Vision-профили.

5. Статус `ПОДКЛЮЧЕН` не равен полной работоспособности Claude / ChatGPT / YouTube.

VPN может быть подключён, но конкретный сайт может ломаться из-за DNS, websocket, браузерной сессии или неудачного транспорта.

## Правила будущих инструкций для Happ Mac

При работе с Happ Mac писать так:

```text
В окне Happ нажми шестерёнку слева сверху.
```

или:

```text
В главном окне Happ нажми `+` справа сверху → `Вставить из буфера обмена`.
```

Не писать абстрактно:

```text
Открой подписки.
```

Вместо этого уточнять:

```text
Если нужно добавить новую ссылку: главное окно Happ → + → URL подписки.
Если нужно управлять уже добавленными подписками: шестерёнка → РАСШИРЕННЫЕ НАСТРОЙКИ → Подписки.
```

## Что ещё нужно доснять при следующем обновлении

Для полной карты не хватает отдельных скриншотов:

1. экран `Настройки → Подписки`;
2. меню `...` у заголовка подписки;
3. экран деталей конкретного маршрута после нажатия на строку `>`;
4. экран `Логи`;
5. экран `Пинг`;
6. экран `On Demand`.

Пока эти экраны не присланы, их элементы не описывать и не додумывать.
