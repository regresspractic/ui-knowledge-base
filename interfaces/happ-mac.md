# Happ Mac — карта интерфейса

Дата актуализации: 2026-06-02

Статус: актуально.

Платформа: macOS.

Язык интерфейса: русский.

Версия по экрану `О приложении`:

- Версия приложения: 4.8.1
- Версия Xray: 26.2.6
- Версия API: 3.13.3
- macOS: 15.7.7

## Назначение карты

Карта нужна, чтобы в будущих инструкциях по VPN-клиенту Happ на Mac не путать:

- главное окно Happ;
- настройки Happ;
- подписки и отдельные маршруты;
- меню добавления конфигураций;
- меню управления подпиской;
- логи, пинг, маршрутизацию и технические Dev Settings;
- интерфейс приложения, реальные папки macOS и файловое дерево проектов.

## Главное окно

Верхняя строка macOS, когда активно приложение:

```text
Happ | Файл | Правка | Формат | Вид | Окно | Справка
```

Внутри окна Happ:

- сверху по центру — заголовок `Happ`;
- слева сверху — стандартные кнопки macOS;
- под ними слева — шестерёнка настроек;
- справа сверху — кнопка `+`;
- в центре — круглая кнопка питания;
- под кнопкой питания — состояние подключения, например `ПОДКЛЮЧЕН`;
- под состоянием — таймер текущей VPN-сессии;
- над списком маршрутов слева — `Проверить текущее соединение`;
- над списком маршрутов справа — `Скрыть все`;
- ниже — список подписок и маршрутов.

Важно: статус `ПОДКЛЮЧЕН` не гарантирует, что конкретный сервис работает. При диагностике разделять:

1. VPN-профиль / транспорт;
2. DNS / сетевую связность;
3. браузер / сессию / авторизацию сайта.

## Кнопка `+` справа сверху

Маршрут:

```text
главное окно Happ → +
```

Открывает меню:

```text
URL подписки
Вставить из буфера обмена
QR-код
Ручной ввод
Копировать JSON
```

Назначение:

- `URL подписки` — добавить подписку по ссылке;
- `Вставить из буфера обмена` — добавить скопированную ссылку / конфигурацию;
- `QR-код` — импорт через QR;
- `Ручной ввод` — ручное создание конфигурации;
- `Копировать JSON` — работа с JSON-конфигурацией.

## Список маршрутов и подписок

Нижняя часть главного окна — список конфигураций.

Есть два типа элементов:

1. отдельные маршруты;
2. группы подписок.

### Отдельная строка маршрута

Строка обычно содержит:

- флаг страны или серую иконку глобуса;
- цветной индикатор состояния / качества;
- название маршрута;
- техническую строку под названием;
- задержку справа: `273 мс`, `832 мс`, `6247 мс` или `n/a`;

## Группа подписки

Группа подписки отображается отдельным блоком с заголовком.

В заголовке видны:

- стрелка раскрытия / сворачивания;
- название подписки;
- дата обновления;
- автообновление;
- кнопка обновления;
- кнопка пинга / проверки;
- меню `...`;
- полоса трафика;
- срок действия.

Примеры:

```text
FRDM VPN
38-180-113-171.sslip.io
vpn.regresspractic.ru
vpn.regresspractic.ru AN
```

Примеры трафика и срока:

```text
239 GB/1900 GB
706 MB/3000 GB
421 MB/3000 GB
Истекает: 19.08.2026
Истекает: 24.05.2036
```

## Меню `...` у подписки

Маршрут:

```text
главное окно Happ → заголовок подписки → ...
```

На примере `FRDM VPN` меню содержит:

```text
Обновить подписку
Пинг
Редактировать
Закрепить
Удалить
```

Назначение:

- `Обновить подписку` — вручную обновить подписку;
- `Пинг` — проверить маршруты подписки;
- `Редактировать` — открыть JSON / настройки подписки;
- `Закрепить` — закрепить подписку в списке;
- `Удалить` — удалить подписку.

## Редактор JSON подписки

Маршрут:

```text
главное окно Happ → подписка → ... → Редактировать
```

Экран показывает JSON-конфигурацию.

Сверху видны:

- кнопка назад;

- кнопка `Обновить`;
- меню `...`;

Внутри JSON видны секции типа:

```text

```

Это технический экран. Не редактировать вручную без необходимости.

## Типовые ошибки

Ошибки отображаются как баннер поверх главного экрана Happ, а не как системное окно macOS.

### Сертификат недействителен

Текст:

```text
Сертификат для данного сервера недействителен. Возможно, Вы подключаетесь к серверу, имитирующему «vpn.regresspractic.ru», что может подвергнуть риску Вашу конфиденциальную информацию.
```

Контекст: ошибка появляется при работе со строками `vpn.regresspractic.ru`.

Не делать автоматически:

- не менять серверную конфигурацию;
- не удалять домен;
- не удалять подписку;
- не считать, что весь VPS сломан.

Сначала диагностировать слой: сертификат / домен / конкретный транспорт / профиль.

### Таймаут соединения

Текст:

```text
Время ожидания соединения истекло. Сервер не отвечает, или возможно проблема с интернет-соединением.
```

### Превышен лимит времени на запрос

Текст:

```text
Превышен лимит времени на запрос.
```

Эта ошибка может появляться во время пинга / проверки маршрутов.

## Типичные пользовательские ловушки

1. `+` и `Настройки → Подписки` — разные места.

```text
+                         добавление новой подписки / конфигурации
Настройки → Подписки      экран добавления URL подписки и параметров подписки
```

2. Группа подписки и маршрут — разные элементы.

```text
FRDM VPN                  группа подписки
FRDM - Обход 7 ×2         конкретный маршрут
```

3. У собственного VPS несколько похожих блоков.

```text
38-180-113-171.sslip.io
vpn.regresspractic.ru
vpn.regresspractic.ru AN
```

В инструкциях всегда называть точный блок.

4. SMART / fragment-профили могут быть нестабильными.

По предыдущим диагностическим случаям FRDM SMART / fragment-профили могли вызывать ошибки XrayCore. Для AI-сервисов предпочтительнее TCP Reality / Vision-профили.

5. `ПОДКЛЮЧЕН` не равно «всё работает».

VPN может быть подключён, но Claude / ChatGPT / YouTube могут ломаться из-за DNS, websocket, браузерной сессии, OAuth или конкретного транспорта.

## Правила будущих инструкций по Happ Mac

Писать конкретно:

```text
В окне Happ нажми шестерёнку слева сверху.
```

```text
В главном окне Happ нажми `+` справа сверху → `Вставить из буфера обмена`.
```

```text
В блоке `FRDM VPN` нажми `...` справа → `Пинг`.
```

Не писать абстрактно:

```text
Открой подписки.
```

Вместо этого уточнять:

```text
Если добавляем новую ссылку: главное окно Happ → + → URL подписки.
Если управляем существующей подпиской: главное окно Happ → нужный блок подписки → ...
Если открываем экран настроек подписки: Настройки → Подписки.
```
